JOURNALY LOCAL BRIDGE

1. Keep Ollama running on http://127.0.0.1:11434.
2. Install a Gemma model in Ollama. For a 12 GB GPU, gemma3:12b is the recommended quality tier; gemma3:4b is the faster option.
3. Extract this ZIP to a permanent folder.
4. Open edge://extensions (or brave://extensions), enable Developer mode, and choose Load unpacked.
5. Select the extracted folder, then reload Journaly OS.

The bridge automatically detects Ollama and lets Journaly ask the local model for private analysis. No clicking, tab authorization, or manual syncing is required after installation.

It has no TradingView permission, does not inspect browser tabs, does not place trades, and does not control a broker. Local model access is restricted to Ollama on 127.0.0.1:11434. The local draft is advisory; Jarvis verifies it against Journaly data before answering.
