# Jarvis Transfer Pack v0.1

This package is a starting bundle for moving the trading-assistant behavior developed in ChatGPT into Journaly OS.

Files:
- jarvis_system_prompt.md
- strategy_rules.json
- decision_examples.json
- post_trade_labels.json
- jarvis_output_schema.json
- journaly_integration_guide.md

This should remain a living package. Update it whenever the strategy changes, a new correction is made, or new labeled examples are added.
